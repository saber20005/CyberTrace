# التوصيات ومراجعة المحلّل

## من مكتبة التحقيقات

تُحسب الاقتراحات من المكتبة الحالية والنتائج المحفوظة في المتصفح:

- **خطوتك التالية:** أول تحقيق غير مكتمل، مع تقديم المستوى الأيسر وترتيب المكتبة عند تساوي المستوى.
- **فرصة للتحسين:** التحقيق صاحب أقل أفضل نتيجة دون 70 نقطة. عند عدم وجود نتيجة قابلة للتحسين، يمكن اقتراح إعادة تحقيق قديم مكتمل دون نتيجة مسجّلة.
- **اقتراح اليوم:** قضية مختلفة عن البطاقات الأخرى، يتغيّر اختيارها حسب التاريخ المحلي وقائمة القضايا المتاحة للاقتراح. لا تضيف مكافأة أو مهلة، وتستخدم آلية النقاط المعتادة.

عرض التوصيات لا يغيّر الإكمال أو عدد المحاولات أو رصيد النقاط. إذا أصبحت كل النتائج كاملة، تبقى بطاقة اقتراح للمراجعة.

خريطة المجالات داخل عنصر قابل للفتح تعرض مجموع أفضل النتائج مقابل النقاط المتاحة لكل مجال. النسبة تعني تغطية نقاط مكتبة التدريب، ولا تعني إثبات كفاءة مهنية. يُعرض الإنجاز القديم دون نتيجة محفوظة على أنه غير مسجّل، دون تعيين درجة افتراضية.

## بعد إكمال التحقيق

تعرض «مراجعة المحلّل» الدليل الذي اختير وتقييمه، والقرار وأثره، وتفصيل نقاط الدليل والقرار وخطوة التحسين التالية. لا تظهر المراجعة أو إمكانية التنزيل قبل إكمال المحاولة.

زر «تنزيل تقرير التحقيق» ينشئ ملف Markdown عربيًا محليًا. يحتوي على نتيجة المحاولة وأفضل نتيجة وعدد المحاولات ووقت الإكمال المحفوظ ورابط التدريب العملي. لا يتضمن هوية الحساب أو البريد أو إعدادات Firebase، ولا يُرسل إلى BlackBox تلقائيًا. يبقى وقت التقرير هو وقت إكمال المحاولة عند إعادة التنزيل.

لا تتطلب هذه الإضافات أي تغيير لقواعد Firestore أو إعداد خدمة جديدة.

## التحقق

```sh
npm test
npm run lint
npm run build
```

تغطي `learning-plan.test.mjs` التوصيات والمكتبة الفارغة والإنجاز القديم والنتائج غير الصالحة وعدم تعديل البيانات. وتغطي `investigation-report.test.mjs` تطابق الاختيارات والنقاط ووقت الإكمال ورفض المحاولات الناقصة.
