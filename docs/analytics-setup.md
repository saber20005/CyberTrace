# تفعيل قياس الاستخدام

## الحالة الحالية

القياس المركزي **معطّل** لأن مالك الموقع لم ينشئ بعد معرّف Google Analytics 4. لا يحمّل التطبيق وسم Google ولا يرسل أحداثًا إلى Google عند بقاء حقل المعرّف فارغًا أو غير صالح. أحداث التدريب موجودة في الشيفرة وجاهزة للربط؛ لا توجد لوحة أرقام تجريبية أو حساب تحليلات مُنشأ نيابة عن المالك.

## التفعيل بواسطة المالك

1. افتح [Google Analytics](https://analytics.google.com/)، وأنشئ حسابًا وخاصية GA4 قياسية، ثم مصدر بيانات من نوع Web للموقع المطلوب. اتبع [دليل Google الرسمي لإنشاء الخاصية ومصدر البيانات](https://support.google.com/analytics/answer/9304153).
2. انسخ Measurement ID الذي يبدأ بـ `G-` من تفاصيل مصدر الويب. هذا معرّف عام يظهر في الموقع؛ لا تستخدم كلمة مرور أو مفتاح API أو سرّ Measurement Protocol مكانه.
3. ضع المعرّف الحقيقي في `index.html` داخل وسم `meta` الذي اسمه `google-analytics-id`، في خاصية `content` الفارغة. لا تستخدم معرّفًا تجريبيًا أو معرّف مشروع آخر.
4. كرّر الإعداد للموقع الثاني بمعرّفه المناسب، ثم انشر التغييرين عبر مراجعة الشيفرة المعتادة.
5. في إعدادات مصدر الويب، عطّل Enhanced Measurement التلقائي. يرسل التطبيق مشاهدات الصفحات يدويًا وأحداثًا محددة؛ إبقاء تتبّع تغيرات سجل المتصفح مفعّلًا قد يكرر مشاهدات الصفحات، كما أن القياس التلقائي للنماذج والروابط لا يمر عبر قائمة الحقول المسموح بها في التطبيق.
6. شغّل تجربة على النطاق الأساسي المنشور وافتح تقرير Realtime. ابدأ تدريبًا وأكمله، وتحقق من ظهور الأحداث المناسبة. يمكنك استخدام أدوات Google للتحقق، لكن نجاح إدراج الحدث في طابور الوسم لا يثبت وحده أن خوادم Google استلمته.

يدعم المالك إعداد خصائص منفصلة أو إعداد رحلة مشتركة بين النطاقين وفق احتياجه. لا تجمع مستخدمي الموقعين على أنهم أشخاص فريدون دون إعداد قياس العبور بين النطاقين المناسب. لا يضيف هذا الربط معرّف مستخدم مشتركًا أو مزامنة لتقدّم التدريب.

## الأحداث

| الحدث | الاستخدام والحقول المسموحة |
|---|---|
| `page_view` | مشاهدة عنوان معروف داخل الموقع؛ تُزال المعلمات غير المعروفة والجزء بعد `#`، وتُقبل معلمات حملة ذات صياغة محدودة |
| `training_start` | بدء تحقيق: `case_id`, `difficulty`, `source` |
| `training_complete` | إكمال التحقيق: `case_id`, `score` |
| `track_open` | فتح مسار: `track_id` |
| `stage_start` | فتح مرحلة: `track_id`, `stage_index` |
| `stage_complete` | تأكيد مرحلة: `track_id`, `stage_index` |
| `partner_click` | الانتقال إلى الموقع الآخر: `destination`, `context` |
| `report_export` | تنزيل التقرير: `format` |
| `backup_export` | تنزيل النسخة: `format` |
| `backup_restore` | استعادة النسخة: `completed_count` |

تُستخدم الأحداث الخاصة بكل موقع فقط. لا يرسل الربط نصوص الملاحظات أو نتائج المختبر المكتوبة أو البريد الإلكتروني أو الأوامر أو الحقول غير المعروفة. تأكيد المرحلة في BlackBox-Lab مؤشر استخدام يقرّه المستخدم، وليس تحققًا آليًا من تنفيذ الأدوات.

## تقارير الحملة

- استخدم معلمات `utm_source` و`utm_medium` و`utm_campaign` و`utm_content` كمعرّفات حملة قصيرة، دون أسماء أشخاص أو بريد أو معلومات خاصة.
- في إعدادات GA4 يمكن تعيين `training_complete` و`stage_complete` كأحداث رئيسية. سجّل الحقول اللازمة مثل `case_id` و`track_id` كأبعاد مخصصة إذا احتجت تحليلها في التقارير، وفق [دليل معلمات الأحداث](https://developers.google.com/analytics/devguides/collection/ga4/event-parameters).
- قارِن الزيارات بالبدايات والإكمالات، وراجع كل موقع على حدة قبل استنتاج التحويل بينهما.

## حدود التشغيل والاختبار

- تتبع النطاقات الأساسية المنشورة فقط؛ لا تُجمع زيارات المعاينات أو localhost افتراضيًا.
- تُحترم إشارتا Do Not Track وGlobal Privacy Control. قد تمنع إضافات الخصوصية أو الشبكة وصول الوسم؛ يظل التدريب يعمل في هذه الحالات.
- إعلانات Google وإشارات التخصيص الإعلاني غير مفعّلة في إعداد الوسم.
- واجهة `trackPageView()` تمنع تكرار مشاهدة العنوان نفسه عند إعادة الرسم أو تأثيرات React المتكررة، وتُستدعى بعد تغيير المسار وعنوان الصفحة.
- فحوص Node تستخدم متصفحًا ووسمًا محقونين داخل الاختبار للتحقق من التعطيل، والتنقية، والتكرار، والتعامل مع الفشل. لا ترسل هذه الفحوص زيارات إلى خاصية Google حقيقية.

مراجع التنفيذ: [أحداث GA4](https://developers.google.com/analytics/devguides/collection/ga4/events)، [قياس مشاهدات الصفحات](https://developers.google.com/analytics/devguides/collection/ga4/views)، [إعدادات الوسم](https://developers.google.com/analytics/devguides/collection/ga4/reference/config).
