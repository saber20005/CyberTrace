# عرض الصفحات الموحد

تستخدم الصفحات إطار `SiteShell` للتنقل ومسار الصفحة والعودة إلى المحتوى بلوحة المفاتيح، وتبقى شاشة التحقيق في وضع تركيز بأدواتها الخاصة. يحافظ `embedded` على استعمال المكونات مستقلة في الاختبارات دون تكرار الترويسات داخل التطبيق.

تجمع متغيرات `design-system.css` الألوان والمسافات وأحجام النص. وتضبط `page-layout.css` اتساع المحتوى والعناوين والنماذج والبطاقات عبر المكتبة والمسارات وSOC والحساب والشهادات وإعدادات العرض. تعمل التفضيلات المحلية القائمة دون تغيير حقولها أو تحويلها إلى إعدادات حساب.

لم تتغير المصادقة أو Firebase أو صلاحيات الإدارة أو آلية المزامنة والنقاط والتقييم أو بيانات التحقيقات. تبقى مسميات الشهادة التجريبية والنتيجة غير الموثقة واضحة، وتبقى أوراق الشهادات وقواعد طباعتها مستقلة عن تنسيق المنصة.

فحص `scripts/test-page-presentation-browser.mjs` يشغّل التطبيق الفعلي خلف مصادقة وهمية محلية وربط خارجي معطل ضمن خادم الاختبار فقط. يغطي المقاسات320/390/768/1440 والسمات، والتنقل الحقيقي، وحفظ إعدادات العرض، والاختصارات، والتحقيق في وضع التركيز، وعزل حسابات اصطناعية، والتفاف أزرار معاينة الشهادة مع خطوط بديلة واستبعاد عناصر التنقل من الطباعة. لا يغيّر خادم الاختبار إعدادات الإنتاج ولا يُضمّن مدخله ضمن بناء Vite.

يفحص `scripts/test-home-navbar-browser.mjs` الترويسة الفعلية مع نافذة ربط محلية وهمية على الهاتف وسطح المكتب، ويتحقق من بقاء زر الفتح ظاهرًا واستعادة التركيز بعد الإغلاق بالنقر أو Escape، دون طلبات خارجية.
