# مركز التحقيق المتقدم — ثلاث قضايا

## الوضع الحالي
أُطلق مركز التحقيق كميزة إضافية داخل مرحلة **الأدلة** في ثلاث قضايا موجودة سلفًا، دون إضافة أو حذف قضية من المكتبة:
- **INC-0417 — تسجيل دخول مشبوه**: 12 حدثًا مصطنعًا متسلسلًا، مع بقاء الملاحظات القديمة في مكانها
- **INC-1207 — تغيير ثقة موفّر الهوية**: 7 أحداث مشتقة مباشرة من `logLines` الأصلية للقضية، تربط إعداد الثقة والجلسة والصلاحيات
- **INC-1208 — طلب دفع مورد غير معتمد**: 7 أحداث مشتقة مباشرة من `logLines` الأصلية، تربط البريد وسجل المستفيد والتحقق المستقل وحالة التحويل

في القضايا الجديدة، يُعرض النص الأصلي للسجل دون تغيير، بينما يضيف المركز تعليقات شرح منفصلة. هذه كلها **محاكاة تدريبية** وليست سجلات حقيقية ولا تحققًا خادميًا لنتائج المستخدم.

## أدوات التحقيق
- خط زمني قابل للبحث والتصفية حسب نوع الحدث
- فحص تفصيلي لسطر السجل مع شرح متحفظ
- تثبيت حتى ستة أحداث مهمة
- **مقارنة زمنية بين أي حدثين مثبتين** مع حساب الفاصل بالثواني، والتنبيه صراحةً إلى أن التزامن لا يثبت السببية
- فرضية ملائمة لكل قضية، وملاحظة بحد أقصى 1200 حرف
- تصدير Markdown للأدلة والفرضية والمقارنة الزمنية

## الحفاظ على بيانات المستخدم
- لا تعديل في `addXP` أو `recordCaseResult` أو `BlackBoxResult` أو `recordCompletion` أو `cloudProgress` أو قواعد Firestore
- لا تمنح الأدلة المثبتة والفرضيات أو المقارنات أي XP إضافي
- تحافظ الحالة `INC-0417` على مفتاح التخزين السابق نفسه دون ترحيل أو حذف
- دفتر التحقيق محلي حسب UID والقضية عبر `progressKey("cybertrace_analyst_workspace:" + caseId)`، ولا يتزامن بين الأجهزة في هذه المرحلة؛ نتائج التحقيق الرسمية داخل واجهة التطبيق تظل على مسار المزامنة الحالي مع BLACKBOX
- تغيير حساب المستخدم لا يكشف دفاتر الحسابات الأخرى المخزنة في المتصفح نفسه
- كل القضايا الأخرى تتبع مسار تحليل الأدلة القديم كما كان

## فحص الجودة
- `npm run lint`
- `npm test` (يشمل العزل، التصفية، المطابقة مع السجلات الأصلية، صحة مقارنة الأوقات وحفظ الدفتر القديم)
- `npm run build`
- اختبارات قواعد Firestore باستخدام المحاكي
- بعد الدمج: التحقق من ظهور القضايا الثلاث على النطاق العام، وفحص التصفية والأدلة من المتصفح بلا حساب

## خطوات التجربة
1. افتح إحدى القضايا عبر رابط `?case=INC-0417` أو `?case=INC-1207` أو `?case=INC-1208`
2. اختر «ابدأ التحليل» وافتح أكثر من حدث
3. ثبّت حدثين، ثم اخترهما في لوحة «مقارنة الأدلة المثبتة»
4. جرّب البحث والتصفية، ودوّن فرضية وملاحظة
5. نزّل Markdown، ثم أكمل التحقيق بالأسلوب القديم
6. افتح الصفحة بحساب آخر، وتأكد من عدم ظهور ملاحظات الحساب الأول
