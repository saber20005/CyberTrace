# CyberTrace

منصة تدريب عربية على التحقيق في الحوادث الأمنية وتحليل السجلات واتخاذ قرارات الاستجابة.

## ما توفره المنصة

- مكتبة تضم 16 تحقيقًا مع البحث والتصفية حسب المستوى والمجال وحالة الإنجاز.
- اختيار قضية محددة أو تحقيق عشوائي من القضايا غير المكتملة في الدورة الحالية.
- رحلة من أربع مراحل: الحادثة، تحليل الأدلة، اتخاذ القرار، والنتيجة؛ حتى 70 XP لكل محاولة.
- لوحة تقدّم تعرض القضايا المكتملة والرصيد والمحاولات المسجّلة وأفضل نتيجة.
- سجل لكل قضية يتضمن أفضل وآخر نتيجة وعدد المحاولات وتاريخ آخر إكمال.
- توصيات للتحقيق التالي ومراجعة النتائج القابلة للتحسين، واقتراح يومي من المكتبة الحالية دون مكافآت إضافية.
- خريطة تغطية مجالات التحقيق من أفضل النتائج المسجّلة، مع تمييز الإنجازات القديمة دون نتيجة.
- مراجعة للمحلّل بعد المحاولة وتقرير Markdown يضم الدليل والقرار وتفصيل النتيجة وخطوات المتابعة.
- واجهة RTL متجاوبة مع الهاتف، مع الإبقاء على تسجيل الدخول الحالي عبر Firebase.
- روابط مباشرة قابلة للمشاركة للمكتبة ولكل قضية، مع دعم الرجوع والتقدم في المتصفح.
- انتقال إلى التدريب العملي ذي الصلة في BlackBox-Lab، الذي ينظّم المختبر المحلي وتوثيق نتائجه.
- تحكّم مختصر بربط BlackBox في رأس الصفحات، مع تفاصيل الحساب ونقل النتائج وإعادة المزامنة داخل نافذة الإدارة.

راجع [دليل التوصيات والتقرير](docs/guided-learning.md) و[أفكار التطوير التالية](docs/product-roadmap.md).

## الروابط والمشاركة والظهور في البحث

- الصفحة الرئيسية: `https://cyber-trace-psi.vercel.app/`
- المكتبة: `https://cyber-trace-psi.vercel.app/?view=library`
- مثال لقضية: `https://cyber-trace-psi.vercel.app/?case=INC-1104`

تُفتح هذه الروابط مباشرة بعد التحديث أو مشاركتها، وتُراجع معرّفات القضايا قبل عرضها. تُحفظ معلمات الحملة في شريط العنوان عند التنقل، بينما تستخدم الروابط الأساسية ونسخ المشاركة عنوانًا نظيفًا دون معلمات تتبع أو مرشحات بحث.

يحتوي الموقع على `robots.txt` و`sitemap.xml` للمكتبة والقضايا الحالية، ووسوم Open Graph وTwitter مع بطاقة PNG مشتركة. تتحدّث عناوين الصفحات ووصفها وروابطها الأساسية داخل المتصفح بحسب القضية. خدمات المشاركة التي لا تشغّل JavaScript تستخدم بطاقة الموقع العامة؛ لا يقدّم البناء الثابت صورًا مستقلة مولّدة من الخادم لكل قضية. ينبغي طلب الفهرسة من حساب مالك الموقع في Search Console؛ وجود خريطة الموقع لا يعني تسجيله تلقائيًا.

## التشغيل المحلي

يتطلب المشروع Node.js المتوافق مع Vite 8 (الإصدار المستخدم في النشر: Node.js 24).

```sh
npm ci
npm run dev
npm run build
npm run lint
npm test
```

## حفظ التقدّم

النتائج والنقاط محفوظة في متصفح الجهاز، ولا تتزامن تلقائيًا مع حساب Firebase أو الأجهزة الأخرى. يحتفظ التحديث بمفاتيح `cybertrace_xp` و`cybertrace_seen_cases` القديمة، ويضيف تاريخ الإكمال الدائم وسجل النتائج. تظهر القضايا القديمة كمكتملة دون اختراع نتائج أو عدد محاولات لم يكن محفوظًا سابقًا.

بعد إكمال كل القضايا تبدأ دورة عشوائية جديدة، مع بقاء تاريخ الإنجاز وأفضل النتائج. إذا منع المتصفح التخزين يستمر التقدّم خلال الجلسة الحالية فقط.

تغطي اختبارات Node ترحيل التقدّم القديم، وحفظ تاريخ الإنجاز عبر الدورات، وأفضل وآخر نتيجة والمحاولات، ومعالجة التخزين المعطّل أو الممتلئ دون فقدان تقدّم الجلسة.

## قياس الاستخدام

ربط Google Analytics 4 اختياري، وهو غير مفعّل افتراضيًا لأن وسم `google-analytics-id` فارغ. لا يحمّل الموقع مكتبة Google أو يرسل أحداثًا عند غياب معرّف قياس حقيقي. عند إعداده تُقاس مشاهدة الصفحات وبدء التحقيق وإكماله والانتقال إلى الموقع الآخر، دون إرسال أسماء المستخدمين أو بريدهم أو محتوى الملاحظات.

راجع [إعداد القياس](docs/analytics-setup.md) لخطوات تفعيل معرّف المالك والتحقق منه. تبقى المعاينات وبيئات التطوير دون قياس افتراضيًا.
